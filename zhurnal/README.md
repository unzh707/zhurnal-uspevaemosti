# Учёт успеваемости (Журнал)

Учебный проект на Flask: веб-приложение для преподавателя, позволяющее вести
группы, студентов и оценки — «электронный журнал».

## Функциональность

- Регистрация и вход преподавателя (Flask-Login), хеширование паролей с солью
  (PBKDF2-SHA256 через Werkzeug).
- ФИО преподавателя и студента хранится как три отдельных поля — Фамилия,
  Имя, Отчество (отчество необязательно) — для корректной сортировки
  и поиска, с едиными заголовками через свойство `full_name`.
- Создание учебных групп, привязка предметов к группе.
- Добавление студентов в группу.
- Выставление оценок студентам по предметам, история оценок.
- Автоматический расчёт среднего балла студента.
- Поиск групп по названию и поиск студентов внутри группы (через GET-параметры).
- Изоляция данных: каждый преподаватель видит и редактирует только свои
  группы/студентов/оценки.

## Технологии

- **Backend:** Python 3, Flask, Flask-SQLAlchemy (ORM), Flask-Login, Werkzeug.
- **Frontend:** HTML5, CSS3 (Grid/Flexbox, медиазапросы), Jinja2 (шаблонизатор
  с наследованием `extends` / `block` / `super()`).
- **База данных:** SQLite.

## Структура базы данных (ORM-модели)

| Модель            | Тип связи                          |
|-------------------|-------------------------------------|
| `Teacher` ↔ `TeacherProfile` | one-to-one              |
| `Teacher` → `Group`          | one-to-many              |
| `Group` → `Student`          | one-to-many              |
| `Student` → `Grade`          | one-to-many              |
| `Subject` → `Grade`          | one-to-many              |
| `Group` ↔ `Subject`          | many-to-many (`group_subjects`) |

Схема (упрощённо):

```
Teacher 1───1 TeacherProfile
Teacher 1───N Group N───N Subject
                Group 1───N Student 1───N Grade N───1 Subject
```

## Установка и запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Приложение будет доступно на `http://127.0.0.1:5000/`.
При первом запуске автоматически создаются таблицы БД (`db.create_all()`).

1. Откройте `/auth/register` и создайте преподавателя.
2. Войдите и создайте первую группу.
3. Добавьте предмет(ы) группе, добавьте студентов.
4. Откройте карточку студента и выставите оценку — средний балл посчитается
   автоматически.

## Как в проекте закрыты технические требования

1. **Архитектура и шаблоны** — маршрутизация через Flask Blueprints
   (`auth`, `main`); во всех шаблонах используется синтаксис Jinja2
   `{{ }}`, `{% %}`, `{# #}`; наследование шаблонов реализовано в два уровня
   (`base.html` → `main/_layout.html` → конкретная страница) с использованием
   `extends`, `block` и `{{ super() }}` (см. `app/templates/main/student.html`).
2. **База данных** — модели описаны в `app/models.py` через Flask-SQLAlchemy;
   показаны все три типа связей: one-to-one, one-to-many, many-to-many.
3. **Аутентификация и безопасность** — `flask_login.login_user`,
   `logout_user`, `current_user`, декоратор `@login_required` закрывают все
   защищённые маршруты; пароли хешируются с солью через
   `werkzeug.security.generate_password_hash` (PBKDF2-SHA256).
4. **Работа с данными** — все формы (регистрация, вход, создание группы,
   добавление студента, выставление оценки) обрабатываются через
   `request.form`; поиск групп (`?q=`) и поиск студентов внутри группы
   (`?search=`) реализованы через `request.args`.
